# Ciência de Dados e Estatística · UFU — landing page

Página de divulgação do **Bacharelado em Ciência de Dados e Estatística** da Universidade Federal de Uberlândia (IME/UFU), feita para estudantes do ensino médio.

🔗 **No ar:** https://matheusguerrero.github.io/ciencia-de-dados-ufu/
🎓 **Site oficial do curso:** https://www.ime.ufu.br/graduacao/ciencia-de-dados-e-estatistica

## O que tem na página

- Hero com uma **regressão linear interativa** (arraste os pontos e a reta se ajusta ao vivo)
- O que é ciência de dados, o que se aprende (com disciplinas reais da grade 2026) e onde atuar
- "Green flags" do curso, reportagens sobre a profissão e perguntas frequentes
- Link para o site oficial em vários pontos

## Fontes

- Projeto Pedagógico do Curso (PPC 2026) e grade curricular 2026.1, publicados em ime.ufu.br
- Reportagens: Comunica UFU, Canaltech, Exame, Correio e Fast Company Brasil (links na página)
- Fotos: Unsplash (créditos no rodapé da página)

## Estrutura

Site estático, sem build: `index.html`, `styles.css`, `main.js`, `favicon.svg` e `og.png` (imagem de compartilhamento).
Para editar, basta alterar os arquivos e fazer push na branch `main`; o GitHub Pages publica sozinho.
Ao mudar `styles.css` ou `main.js`, aumente o número em `?v=` no `index.html` para evitar cache antigo.
